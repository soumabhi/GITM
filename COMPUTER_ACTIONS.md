# Computer actions

Actions the ghost can hear.
Nothing here stores what you typed or a file name. Only that the action happened.

## Already on

- Typing. Any letter or number.
- Copy. Ctrl+C, or the clipboard changes.
- Paste. Ctrl+V.
- Delete. The Delete key, or a file disappears from a watched folder.
- Enter.
- Screenshot. Print Screen.
- Scroll.
- Idle. After 12 seconds with no movement, several copies appear at random spots, each on a different frame, and each drifts its own way. When you move, they leave one by one, and each one leaves differently.
- Drag. While you drag something, the character stays on its right and pushes it, facing the way it already faces.
- Close the app. Alt+F4.

Backspace is not Delete.
